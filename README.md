# 新宿ワイルド（試作版 v0.8.0）

ミニチュアダックスとして群れを増やしながら、肉食に食い尽くされるまで粘るブラウザゲームの試作版です。「守るゲーム」「攻めるゲーム」と、敵のいない「パレード」があります。

- 遊ぶ: https://hosomen-game.github.io/shinjukuwild/
- **守るゲーム**: 巣の子犬5匹を、食べに来る肉食から守ります。食べるとまず自分の体力が回復し、余りが繁栄ゲージに入って巣に子犬が生まれます。傷ついた子犬は治りません。子犬が尽きたら終わりです
- **攻めるゲーム**: 子犬を連れて狩りに出ます。噛みついた相手には群れ全員が飛びかかります。繁栄ゲージが満タンになると巣で子が生まれ、走って合流します。群れの数が残機です。外周から野火が迫り、動ける範囲が狭まります
- **パレード**（60・90・120秒）: 敵も攻撃もありません。12種類の動物に触れると、仲間になって列についてきます。どの動物にも7色の色違いがあり、合流すると名前が出ます（全84種、集めた数は図鑑として記録）。気づかれると逃げられるので、後ろからそっと近づきます。Space（スマホはダッシュボタン）を押している間は速く走れますが、気づかれやすくなります。自分の列にぶつかると、そこから後ろが切れます
- 30秒ごとに危険度が上がり、弱い肉食から順に現れます（キツネ→オオカミ→ヒョウ→クマ→ライオンの群れ）
- 獲物は正面から近づくと逃げます。背後か草むら、柱の陰から近づいて飛びかかります
- のんびりモードは現在非表示です（コードには残っています）

## 操作

- PC: WASD で移動、Space で飛びかかり（連打でダッシュ代わり）、ドラッグでカメラ回転、Esc でメニュー
- スマホ・タブレット: 左のスティックで移動、攻撃ボタンで飛びかかり、画面ドラッグでカメラ回転
