# 新宿ワイルド（試作版 v0.3.2）

ミニチュアダックスの群れとして、群れが尽きるまで生き延びるブラウザゲームの試作版です。

- 遊ぶ: https://hosomen-game.github.io/shinjukuwild/
- 狩って空腹を満たし、子育てゲージを貯めて巣に戻ると子が生まれます。群れの数が残機です
- 30秒ごとに危険度が上がり、ライオンが増えていきます
- 地面の扇形は動物の視界です。背後か草むら、柱の陰から近づいて飛びかかります

## 操作

- PC: WASD で移動、Space で飛びかかり（連打でダッシュ代わり）、ドラッグでカメラ回転、Esc でメニュー
- スマホ・タブレット: 左のスティックで移動、攻撃ボタンで飛びかかり、画面ドラッグでカメラ回転
